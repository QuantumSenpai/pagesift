# PageSift Extension Specification and 15-Tool Feature Matrix

## 1. Core Product Principles

1. **100% Free, Local-First, Open-Source Chrome Extension (Manifest V3)**:
   - No mandatory login, no subscription gates, and no mandatory backend or PostgreSQL dependency.
   - All 15 tools execute locally inside the browser extension.
2. **Isolated Extension Storage**:
   - **IndexedDB (`pagesift_local_db`)**: Stores saved projects, multi-page captures, artifacts (`DESIGN.md`, rebuild prompts, token exports, asset manifests, snapshots, screenshots, design reviews, tech stack reports), and recoverable background job states with versioned schema migrations (`v1` -> `v2`).
   - **`chrome.storage.local`**: Stores small non-secret user preferences (theme, default export formats, color/spacing units, responsive presets, optional NVIDIA model ID and endpoint preference).
   - **`chrome.storage.session`**: Stores the user's optional NVIDIA API key (`nvapi-...`) in memory for the current browser session only by default.
   - **Strict Boundary**: PageSift never writes extension data or API keys into an inspected website's `localStorage`, `sessionStorage`, `IndexedDB`, cookies, or DOM globals.
3. **Optional Backend Compatibility**:
   - The Fastify/PostgreSQL backend in `src/` remains intact, tested, and optional for teams that want self-hosted cloud sync later.

## 2. Extension Architecture

- **`src/extension/protocol/`**: Zod-validated runtime message schemas with `schemaVersion: 1`, `requestId`, `operation`, `tabId`, `frameId`, `documentId`, payload validation, sender verification (`validateTrustedExtensionSender`, `validateContentScriptSender`), and cancellation tokens.
- **`src/extension/storage/`**:
  - `idb-storage.ts`: Versioned IndexedDB wrapper (`v1` initial stores `projects`, `artifacts`, `captures`; `v2` adds `jobs` store and compound indexes), transactional writes, quota-error classification, JSON/ZIP backup export and validated import, deletion, and byte-usage reporting.
  - `settings-storage.ts`: Validated `chrome.storage.local` preferences and `chrome.storage.session` NVIDIA API key management.
- **`src/extension/engines/`**: Modular, pure/DOM-callable engines for all 15 tools plus the optional NVIDIA NIM client adapter (`src/extension/ai/nvidia-client.ts`).
- **`src/extension/content/`**: Content script (`content-script.ts`) managing the shadow-DOM isolated dock/overlay (`data-pagesift-root="true"`), throttled pointer inspection (`requestAnimationFrame`), document binding (`documentId`), measurement guides, and reversible edit history (`EditText`, `SwapFont`, `Arrange`).
- **`src/extension/background/`**: Manifest V3 service worker (`service-worker.ts`) handling message routing, persisted job state in IndexedDB, tab capture throttling, download coordination, responsive preview window lifecycle, and optional NVIDIA API requests.
- **`src/extension/ui/`**:
  - `workspace.html` / `workspace.ts`: Extension popup & full workspace panel providing controls for all 15 tools, project/artifact browser, screenshot crop/annotation & PNG/JPEG/WebP/PDF export, responsive multi-viewport controller, and optional NVIDIA enhancement modal with explicit data-egress preview.
  - `options.html` / `options.ts`: Options page for default preferences, NVIDIA API key/model configuration, storage quota & usage inspection, and full IndexedDB backup/import/reset.

## 3. 15-Tool Feature Matrix

| # | Tool | Engine Module | Extension Control | Core Local Behavior | Honest Limitations |
| :- | :--- | :--- | :--- | :--- | :--- |
| 1 | **Inspect** | `src/extension/engines/inspect-engine.ts` | Dock & Workspace Inspect Tab | Hover/click element selection, safe HTML serialization, tag/attributes, bounding box, computed layout/typography/colors/spacing/borders/shadows/radius, accessible name/role, open shadow root traversal, zoom/scroll alignment, excludes `[data-pagesift-root]`. | Computed styles reflect resolved cascade values, not original authored CSS selector rules. Cross-origin iframes and closed shadow roots cannot be pierced and are explicitly reported. |
| 2 | **Clone Page** | `src/extension/engines/clone-page-engine.ts` | Workspace Clone Page Tab | Exports static HTML/CSS snapshot ZIP (`fflate`) with asset manifest, relative URL resolution, CSS `url(...)` rewriting, safe collision-free filenames, missing-resource report, bounded downloads/byte limits, progress/cancellation; strips `<script>`, inline `on*` handlers, `javascript:` URLs, and sensitive form/password values. | Captures static client-side DOM/CSS state only; does not recreate server backends, private APIs, or dynamic JS runtime state. Cross-origin stylesheets blocked by CORS fall back to computed-style synthesis. |
| 3 | **Clone Prompt** | `src/extension/engines/clone-prompt-engine.ts` | Workspace Clone Prompt Tab | Locally generates structured rebuild prompts from extracted layout landmarks, typography, palette, spacing, components, and asset inventory; separates verified observations from structural assumptions; supports optional NVIDIA refinement. | Local prompts are deterministic structural blueprints; optional AI refinement requires a user-supplied NVIDIA API key. |
| 4 | **Design MD** | `src/extension/engines/design-md-engine.ts` | Workspace Design MD Tab | Generates deterministic `DESIGN.md` specifications covering colors, typography, spacing, radius, shadows, layout patterns, component observations, and source references; combines multiple saved page captures, deduplicates tokens, and reports cross-page token conflicts. | Token semantics (e.g. primary vs. accent) are inferred from usage frequency and element roles rather than private Figma token names. |
| 5 | **Assets** | `src/extension/engines/assets-engine.ts` | Workspace Assets Tab | Discovers `<img>`, `srcset`, `<picture>`, CSS `background-image`, inline `<svg>`, icons, `<video>`/`poster`, and `@font-face` URLs; provides metadata, safe inert SVG previews, individual download, and bounded ZIP export; distinguishes discovered URLs from accessible bytes. | Streaming media (`blob:`, `mediasource:`, HLS/DASH) and cross-origin CORS-protected binaries are reported as unavailable/protected in the manifest. |
| 6 | **Colors** | `src/extension/engines/colors-engine.ts` | Workspace Colors Tab | Normalizes RGB/RGBA/HSL/Hex colors, alpha transparency, linear/radial gradients, and accessible `--*` CSS custom properties with element usage evidence; exports CSS variables, JSON, SCSS, and Tailwind v3/v4 theme config. | Colors inside raster images or cross-origin canvas contexts are not sampled by DOM style extraction. |
| 7 | **Fonts** | `src/extension/engines/fonts-engine.ts` | Workspace Fonts Tab | Extracts declared `font-family` stacks, computed size/weight/line-height/letter-spacing usage counts, and accessible `@font-face` rules/URLs; explicitly distinguishes declared font stacks from verified loaded faces (`document.fonts.check`). | Browser font fallback substitution inside OS text shaping is only verifiable up to `FontFaceSet` availability. |
| 8 | **Measure** | `src/extension/engines/measure-engine.ts` | Dock & Workspace Measure Tab | Interactive box dimensions, padding/margin visualization, and element-to-element gap/distance calculation; stays aligned on scroll/resize/zoom; `Escape` key cancellation and complete overlay cleanup. | Measures layout bounding client rectangles in CSS pixels. |
| 9 | **Edit Text** | `src/extension/engines/edit-engine.ts` | Dock & Workspace Edit Text Tab | Explicit in-place text node editing preserving nested child markup, with full undo/redo/reset stack; refuses to modify `<input type="password">` or submit forms. | Local preview only; reloading the page or SPA re-hydration resets the live DOM unless exported. |
| 10 | **Capture** | `src/extension/engines/capture-engine.ts` | Workspace Capture Tab | Captures visible viewport, selected region, selected element, and stitched full-page screenshots handling DPR, sticky/fixed header suppression after tile 0, scroll restoration, bounded lazy waits, rate limiting, max dimension caps, crop/annotation, and verified PNG, JPEG, WebP, and PDF export. | Pages exceeding max height cap (16,384 CSS px) or infinite-scroll feeds are truncated at the documented safety boundary. |
| 11 | **Responsive** | `src/extension/engines/responsive-engine.ts` | Workspace Responsive Tab | Opens and coordinates controlled browser popup windows/tabs at configurable device presets (Mobile 375x812, Tablet 768x1024, Laptop 1280x800, Desktop 1440x900) with optional synchronized scrolling (loop-guarded) and one-click cleanup. | Uses real controlled browser windows rather than spoofing mobile user-agent strings or bypassing `X-Frame-Options` / CSP `frame-ancestors`. |
| 12 | **Swap Font** | `src/extension/engines/edit-engine.ts` | Workspace Swap Font Tab | Previews local/system font families on a selected element, matching selector group, or full page; optional user-triggered Google Font stylesheet load with failure handling; full undo/redo/reset. | Remote font loading can be blocked if the inspected page enforces a strict `style-src` / `font-src` CSP; falls back cleanly to local fonts. |
| 13 | **Arrange** | `src/extension/engines/edit-engine.ts` | Dock & Workspace Arrange Tab | Moves (`transform: translate`), hides (`visibility: hidden`), or removes (`display: none`) selected elements as reversible local previews with undo/redo/reset and automatic cleanup on node detachment or navigation. | Local preview via inline transform/display overrides; does not alter underlying website source files. |
| 14 | **AI Slop / Design Review** | `src/extension/engines/design-review-engine.ts` | Workspace Design Review Tab | Evidence-based local design audit detecting weak heading/typographic hierarchy, repetitive card/gradient/shadow treatments, excessive blur/shadow effects, spacing grid outliers, and WCAG 2.1 AA contrast failures; generates actionable suggestions + local fix prompt, with optional NVIDIA interpretation. | Heuristic audit of observable design quality only; explicitly does not claim to prove AI authorship or output authorship probabilities. |
| 15 | **Tech Stack** | `src/extension/engines/tech-stack-engine.ts` | Workspace Tech Stack Tab | Detects frameworks, CSS libraries, UI kits, analytics, build tools, and meta generators from public DOM markers, script/stylesheet URLs, and meta tags; outputs technology, category, concrete evidence array, confidence level, and uncertainty notes. | Relies strictly on public client-side signals; absence of a marker does not prove a server-side technology is absent. |
