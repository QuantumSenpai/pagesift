# PageSift Extension Specification and 15-Tool Feature Matrix

## 1. Core Product Principles

1. **100% Free, Local-First, Open-Source Chrome Extension (Manifest V3)**:
   - No mandatory login, no subscription gates, and no mandatory backend or PostgreSQL dependency.
   - All 15 tools execute locally inside the browser extension.
2. **Isolated Extension Storage**:
   - **IndexedDB (`pagesift_local_db`)**: Stores saved projects, multi-page captures, artifacts (`DESIGN.md`, rebuild prompts, token exports, asset manifests, snapshots, screenshots, design reviews, tech stack reports), and recoverable background job states with versioned schema migrations (`v1` -> `v2`).
   - **`chrome.storage.local`**: Stores small non-secret user preferences (theme, default export formats, color/spacing units, responsive presets, optional NVIDIA model ID and endpoint preference).
   - **`chrome.storage.session`**: Stores the user's optional NVIDIA API key (`nvapi-...`) in memory for the current browser session only by default.
   - **Strict Boundary**: PageSift never writes extension data or API keys into an inspected website's `localStorage`, `sessionStorage`, `IndexedDB`, cookies, or DOM globals.
3. **Optional Backend Compatibility**:
   - The Fastify/PostgreSQL backend in `src/` remains intact, tested, and optional for teams that want self-hosted cloud sync later.

## 2. Extension Architecture

- **`src/extension/protocol/`**: Zod-validated runtime message schemas with `schemaVersion: 1`, `requestId`, `operation`, `tabId`, `frameId`, `documentId`, payload validation, sender verification (`validateTrustedExtensionSender`, `validateContentScriptSender`), and cancellation tokens.
- **`src/extension/storage/`**:
  - `idb-storage.ts`: Versioned IndexedDB wrapper (`v1` initial stores `projects`, `artifacts`, `captures`; `v2` adds `jobs` store and compound indexes), transactional writes, quota-error classification, JSON/ZIP backup export and validated import, deletion, and byte-usage reporting.
  - `settings-storage.ts`: Validated `chrome.storage.local` preferences and `chrome.storage.session` NVIDIA API key management.
- **`src/extension/engines/`**: Modular, pure/DOM-callable engines for all 15 tools plus the optional NVIDIA NIM client adapter (`src/extension/ai/nvidia-client.ts`).
- **`src/extension/content/`**: Content script (`content-script.ts`) managing the shadow-DOM isolated dock/overlay (`data-pagesift-root="true"`), throttled pointer inspection (`requestAnimationFrame`), document binding (`documentId`), measurement guides, and reversible edit history (`EditText`, `SwapFont`, `Arrange`).
- **`src/extension/background/`**: Manifest V3 service worker (`service-worker.ts`) handling message routing, persisted job state in IndexedDB, tab capture throttling, download coordination, responsive preview window lifecycle, and optional NVIDIA API requests.
- **`src/extension/ui/`**:
  - `workspace.html` / `workspace.ts`: Extension popup & full workspace panel providing controls for all 15 tools, project/artifact browser, screenshot crop/annotation & PNG/JPEG/WebP/PDF export, responsive multi-viewport controller, and optional NVIDIA enhancement modal with explicit data-egress preview.
  - `options.html` / `options.ts`: Options page for default preferences, NVIDIA API key/model configuration, storage quota & usage inspection, and full IndexedDB backup/import/reset.

## 4. UI Surfaces, Theme System & MV3 Worker Recovery Guarantees

- **Dedicated Toolbar Popup (`popup.html`)**: Fast `380px` launchpad with page inspectability indicator, honest restricted-page notice, quick-launch handoff into the persistent Workspace, on-page inspector dock toggle, theme preference switch, and recent IndexedDB artifacts/jobs.
- **Persistent Workspace (`workspace.html` + `tool-renderers.ts`)**: Responsive Light/Dark/System developer workbench with structured safe DOM views for all 15 tools (no raw JSON by default), collapsible Raw Data disclosure, accessible modals (`Escape` + focus restoration), saved work drawer, and verified zero horizontal overflow across `360px`, `390px`, `768px`, `1280px`, `1440px`, and `200%` zoom.
- **On-Page Shadow DOM Dock (`content-script.ts`)**: Isolated `#pagesift-root-host[data-pagesift-root="true"]` overlay distinguishing hover vs. selected highlights, measurement distance badges, compact bottom-right dock, and `Escape` dismissal.
- **Single-Flight MV3 Worker Recovery (`service-worker.ts`)**: Every message and lifecycle listener awaits the shared `ensureInitialized()` promise before handling operations, ensuring ordinary service-worker wake-up recovers previously `running` jobs to `interrupted`, restores active responsive sessions, and reports structured `STORAGE_ERROR` responses on failure without keepalive loops.
